# Fonts

- **Tinos-Bold.ttf**, **Tinos-Italic.ttf** — Tinos, by Steve Matteson / Monotype,
  published by Google. Licensed under the SIL Open Font License 1.1
  (https://openfontlicense.org). Source: https://github.com/google/fonts/tree/main/ofl/tinos

Tinos is metric-compatible with Times New Roman and is used for the extruded
"GENERIC." sign in the hero (loaded at runtime via `TTFLoader` → `TextGeometry`).
